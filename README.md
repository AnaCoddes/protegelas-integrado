# protegELAS

O **protegELAS** é um aplicativo desenvolvido em conjunto como parte de um projeto acadêmico para o **curso de Psicologia**, com foco em uma pesquisa relacionada à violência contra a mulher.

A aplicação tem como objetivo apresentar um questionário de pesquisa de forma simples e interativa, permitindo que as participantes acessem as perguntas a partir da tela inicial.

### Desenvolvimento

O projeto está sendo desenvolvido **em equipe**, com cada integrante responsável por diferentes partes da aplicação.

Minha contribuição no projeto foi o desenvolvimento da **primeira tela (tela inicial)**, incluindo sua estrutura visual e a navegação para a **segunda tela, onde está localizado o formulário de pesquisa**.

### Tecnologias

* React Native
* Expo
* JavaScript
